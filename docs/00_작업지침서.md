# 00_작업지침서 — 아파트 관리비·실거래가 허브

이 문서는 이 프로젝트를 이어받는 사람 또는 AI(피클·제미나이·그록 등)가 **같은 기준으로** 작업하기 위한 지침입니다.
작업을 시작하기 전에 이 문서를 끝까지 읽고, 바꾼 내용은 이 문서와 `01_구축결과.md`에 함께 반영합니다.

- 프로젝트 폴더: 구글 드라이브 `아파트 관리비·실거래가 허브`
- 코드 저장소(로컬 작업본): `apt-cost-hub` (GitHub 원격은 아래 "배포" 항목 참고)
- 배포 주소: https://apt-cost-hub.pages.dev

---

## 1. 프로젝트 목적

전국 아파트의 **관리비**와 **아파트 매매 실거래**를 시군구·단지 단위로 집계해, 검색과 AI가 인용할 수 있는 **정적 데이터 사이트**로 제공한다.

- 답하는 질문: "○○구 아파트 관리비 평균", "관리비 싼 지역", "○○단지 관리비와 최근 거래", "평당가 낮은 지역"
- 방식: 공개된 공공데이터를 **순수 파이썬(표준 라이브러리)** 으로 집계 → 정적 HTML/JSON 생성 → 무료 정적 호스팅
- 서버·DB·유료 API·LLM 호출 없음(완전 자동화)

## 2. 절대 규칙

1. **무과금**: 유료 플랜·유료 API·서버 호스팅으로 전환하지 않는다.
2. **개인정보 비노출**: 운영자 실명, 개인 계정 핸들, 연락처, 계정 아이디·비밀번호·API 키를 코드·문서·사이트·커밋에 쓰지 않는다. 소스에 개인 식별 문자열 검사가 있고, 검사 목록 자체는 저장소에 두지 않는다(`data/private/`는 커밋 제외).
3. **군 관련 정보 비노출**: 사이트·문서·커밋 어디에도 군 관련 표현이나 소속 정보를 넣지 않는다.
4. **원자료 규정 준수**: 두 원자료 모두 공개·무료이며 출처 표시로 사용한다(이용허락범위 제한 없음). 스크래핑 우회·로그인 우회 금지.
5. **수치를 지어내지 않는다**: 원자료에 없는 값은 비우거나 표에서 뺀다. 추정·보간·보정값을 실제 값처럼 표시하지 않는다.
6. **출처와 기준월을 항상 함께 표기**: 관리비 기준월과 실거래 기준월이 다르므로 헷갈리지 않게 각각 표기한다.

## 3. 데이터 소스

| 데이터 | 원자료 | 받는 방법 | 갱신 |
|---|---|---|---|
| 단지 관리비 | K-apt 공동주택관리정보시스템 자료실 `board seq=21` (관리비공개의무단지 관리비정보) | `scripts/fetch_kapt.py` — 메인 → 게시글 → 파일목록 JSON → 파일 다운로드 (세션 쿠키·CSRF 필요, 스크립트가 처리) | 주 1회(K-apt) |
| 단지 면적·세대수 | 같은 자료실 `board seq=20` (관리비공개의무단지 면적정보) | 위와 동일 | 주 1회 |
| 아파트 매매 실거래 | 국토교통부 실거래가공개시스템 '자료제공' CSV | `scripts/fetch_molit.py` — `GET https://rt.molit.go.kr/pt/xls/ptXlsCSVDown.do?...&srhFromDt=YYYY-MM-01&srhToDt=YYYY-MM-말일` (전국은 1개월 단위만 허용) | 월 1회 |

- 공공데이터포털 등록본: 국토교통부_공동주택 단지 관리비 정보(3039714), 국토교통부_공동주택 단지 면적 정보(15073269).
- **네트워크 주의**: `rt.molit.go.kr`은 접속이 막힌 네트워크가 있다. 다운로드 실패 시 `fetch_molit.py`는 기존 CSV를 지우지 않고 넘어가며, 빌드는 마지막으로 받은 월로 계속된다.

## 4. 데이터 스키마 (`data/processed/dataset.json`)

```
snapshot_date        # K-apt 파일명의 추출일 (예: 2026-11-13)
reference_month      # 관리비 기준월 YYYY-MM (공개가 끝난 최신월)
previous_month       # 전월
provisional          # 기준월이 아직 공개 진행 중이면 true
month_coverage       # 월별 집계 단지 수
quality              # area_suspect(면적 오류 의심) / no_fee(공용관리비 0) 건수
national             # 전국 집계 (단지수·세대수·㎡당·면적)
regions[]            # 시군구: slug, 시도, 시군구, 단지수, 집계단지수, 세대수, 면적,
                     #        fee_m2, total_m2, fee_hh, median_fee_m2, mom_pct, items{16항목}, trade{월별}
complexes[]          # 단지: id(단지코드), 이름, 시도/시군구/동, 세대수, 동수, 면적,
                     #       common_fee, indiv_fee, last_charge, total_fee, items{}, fee_m2,
                     #       total_m2, fee_hh, prev_fee_m2, mom_pct, series{월별}, quality
trade                # 실거래: months[], reference_month, national{월별}, rows, rows_unmatched
```

## 5. 산식(바꾸면 사이트·llms.txt·about·FAQ·JSON-LD를 모두 같이 고친다)

- **㎡당 공용관리비** = 공용관리비 합계 ÷ 관리비부과면적(㎡)
- **지역 값** = Σ공용관리비 ÷ Σ관리비부과면적 (면적 가중평균)
- **세대당 총관리비** = (공용관리비 + 개별사용료 + 장기수선충당금 월부과액) ÷ 세대수
- **중위값** = 지역 내 단지별 ㎡당 값의 중앙값
- **평당가** = 거래금액(만원) ÷ 전용면적(㎡) × 3.305785 → 지역 값은 거래별 값의 **중간값**
- **중간 매매가** = 지역 내 거래금액의 중간값
- **제외 규칙**: 해제된 거래(해제사유발생일 존재), 관리비부과면적÷세대수가 10㎡ 미만·400㎡ 초과인 단지(면적 입력 오류로 판단), 공용관리비 0원 단지
- **기준월 선택**: 집계 단지 수가 최대치의 50% 미만인 월(막 열린 월)은 기준월에서 제외하고, 그 달 집계가 전월의 95% 미만이면 `잠정`으로 표시

## 6. 사이트 구조와 GEO 규칙

- 페이지: `/`(전국·상위 50개 시군구·순위·FAQ), `/region/{slug}`(251개), `/complex/{단지코드}`(1,500개), `/about`, `/privacy`
- 피드: `/api/regions.json`, `/api/regions/{slug}.json`, `/api/meta.json`, `/llms.txt`
- 크롤러: `/sitemap.xml`, `/robots.txt`(AI 크롤러 허용)
- 구조화 데이터: `WebSite`·`WebPage`·`Dataset`·`FAQPage`·`BreadcrumbList` JSON-LD
- **JS 없이 표가 보여야 한다**(AI 크롤러는 JS를 실행하지 않는다).
- **FAQ는 화면과 JSON-LD가 같은 원본**에서 생성되어야 한다(`check_site.py`가 대조).
- URL은 확장자 없는 형태(`/region/daegu-suseonggu`)를 쓴다. 호스팅이 `.html` → 확장자 없음으로 308 리다이렉트하므로 canonical·sitemap·내부 링크를 모두 확장자 없이 쓴다.
- GA4 측정 ID `G-J80R3CFWY8` — 모든 페이지 head에 삽입(익명 IP). 새 페이지 템플릿을 만들 때 빠뜨리지 않는다.
- 단지 페이지는 상위 50개 시군구의 세대수 300 이상 단지 중 상위 1,500개만 만든다(호스팅 파일 수 20,000개 제한과 저장소 크기 때문).

## 7. 실행 순서 (수정 후 반드시 이 순서)

```bash
python3 scripts/fetch_kapt.py      # 관리비·면적 XLSX
python3 scripts/fetch_molit.py     # 실거래 CSV 4개월 (실패해도 기존 파일 유지)
python3 scripts/build_data.py      # dataset.json
python3 -m unittest discover -s tests -v
python3 scripts/build_site.py      # site/
python3 scripts/check_site.py      # 2,800+ 검사, 실패 시 exit 1
```

- `check_site.py`가 0 problems가 아니면 배포하지 않는다.
- 생성물(`site/`, `data/processed/`, `data/raw/*.xlsx|csv`, `data/private/`)은 커밋하지 않는다.

5. 화면 문구는 존댓말·간결체. 숫자 옆에는 항상 단위와 기준월을 붙인다.
